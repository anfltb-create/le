# LE 홈페이지 리뉴얼

별도 빌드 없이 동작하는 HTML·CSS·JavaScript 프로젝트입니다.
VS Code에서 `le` 폴더를 열고 Live Server로 `index.html`을 실행하세요.

## 파일 구성

- `index.html`: 페이지 구조, 상품 정보, 접근성 이름
- `styles.css`: 공통 스타일, PC·태블릿·모바일 배치, 상호작용
- `main.js`: 메뉴, 안내 문구 전환, 히어로 슬라이드, 상품 이미지 준비, 상품 검색, 모바일 푸터
- `assets/`: 이미지, 아이콘, 글꼴
- `.editorconfig`, `.prettierrc.json`: UTF-8, 공백 2칸, 줄 끝과 포맷 기준

## 화면 기준

| 화면   | CSS 폭      |
| ------ | ----------- |
| PC     | 1100px 이상 |
| 태블릿 | 600–1099px  |
| 모바일 | 599px 이하  |

JavaScript의 `media` 객체도 동일한 경계를 사용합니다.
구간을 바꿀 때 CSS와 JavaScript를 함께 수정하세요.

## 클래스 이름

관련 요소는 `구성요소__역할`로 표시합니다.

| 구성요소    | 대표 클래스                                                               |
| ----------- | ------------------------------------------------------------------------- |
| 상단 안내   | `.announcement-bar`, `.announcement-bar__close`                           |
| 모바일 메뉴 | `.mobile-navigation`, `.mobile-navigation__categories`                    |
| 히어로      | `.hero`, `.hero__slide`, `.hero__controls`                                |
| 상품 카드   | `.product-card`, `.product-card__media`, `.product-card__alternate-image` |
| 상품 가격   | `.product-price`                                                          |
| 콘텐츠 폭   | `.page-container`                                                         |

기존 클래스명을 바꾸면 HTML·CSS·JavaScript의 참조도 함께 바꿔야 합니다.

## 자주 수정하는 값

- 안내 문구와 연결 주소: `initializeAnnouncement()`의 `messages`
- 안내 전환: 같은 함수의 `rotationInterval = 4000` (밀리초)
- 안내 X 간격: `.announcement-bar__content`의 `gap: 8px`
- 히어로 자동 전환: `initializeHeroCarousel()`의 `5500` (밀리초)
- 컬렉션 사진 호버 전환: `.product-card__alternate-image`의 `transition`
- 행사상품은 사진을 바꾸지 않고 1.025배 확대합니다.
- OUTER·TOP·BOTTOM 사진은 450ms에 걸쳐 1.03배 확대합니다.
- PC 하단 사진 간격: `.journal`의 `column-gap: 0`, `.space-photos`의 `gap: 0`
- 하단 사진 아래 제목: `.space-story h2`의 `margin-top`
- 모바일 행사 메뉴 간격: `.mobile-navigation .mobile-navigation__sale`

## 상호작용 기준

- 키보드로 메뉴를 열 수 있고 Escape로 닫을 수 있습니다.
- 헤더 검색은 현재 화면에 표시 중인 상품을 검색합니다. 검색 결과를 선택하면 해당 카드로 이동합니다.
- ACCOUNT와 BAG는 르 공식 사이트로 연결됩니다. 이 데모의 장바구니와 연동되는 기능은 아닙니다.
- 모바일 메뉴를 닫으면 열기 버튼으로 포커스가 돌아갑니다.
- 안내와 히어로는 포커스·마우스가 머물면 일시정지합니다.
- 히어로는 화면 밖에 있거나 다른 탭을 볼 때 자동 전환을 멈춥니다.
- 기기의 ‘동작 줄이기’ 설정에서는 자동 전환·장식 애니메이션을 줄입니다.
- 대체 상품 사진이 로드된 경우에만 호버 전환합니다.
- 터치 기기는 첫 상품 사진을 유지합니다.
- 모바일 푸터는 문서 흐름 안에서 펼쳐집니다.

## 범위와 이미지

포트폴리오용 프런트엔드입니다. 실제 로그인·결제 기능은 포함하지 않으며,
외부 상품·안내 링크는 르 공식 사이트로 연결됩니다.
`hero-second-left.png`와 `editorial-comfort-hd.png`는 기존 사진을 AI로 보정한 이미지이므로
실제 상업 배포 전에는 원본 사진과 상품 디테일을 대조하세요.

## 코드 편집

Prettier 확장을 사용하는 경우 폴더의 `.prettierrc.json` 기준으로 포맷할 수 있습니다.
VS Code의 기본 ‘문서 서식 지정’으로도 들여쓰기를 정리할 수 있습니다.
공백 색을 표시하는 확장은 개인 편집기 설정에 따라 표시가 달라질 수 있습니다.

## 반응형 안내와 공간 소개

- 상단 안내 문구는 PC·태블릿·모바일 모두 4초마다 순환합니다.
- 모바일 컬렉션은 좌우 스와이프를 유지하며 스크롤바만 숨깁니다.
- 모바일 공간 소개는 제목 → 흑백사진 → 피그마 원문 설명 순서로 표시합니다.

## 상호작용 조정

- 펼친 PC 헤더의 GNB와 하위 메뉴는 같은 흰색 배경에 불투명도 80%를 사용합니다.
- 태블릿·모바일 메뉴도 같은 80% 배경을 사용하고 350ms로 열립니다.
- 컬렉션 사진은 600ms 동안 부드럽게 교차 전환합니다.
- 맨 위로 버튼은 화면 오른쪽 아래에 고정됩니다.
- 모바일 공간 설명은 중앙 정렬이며, 안내 배너 X는 밝게 표시합니다.

## 사용자 CSS 반영 및 검색 화면

- 사용자가 수정한 모바일 본문 16px, 공간 제목 24px, 상품명 최소 높이를 유지했습니다.
- 헤더와 드롭다운, 모바일·태블릿 메뉴 배경은 90% 불투명도로 통일했습니다.
- 모바일 SHOP 하위 메뉴는 열고 닫을 때 480ms 동안 높이가 부드럽게 변합니다.
- PC 마지막 흑백사진 섹션과 푸터 사이는 화면 폭에 따라 80–120px입니다.
- 검색창은 피그마의 로고·닫기·SEARCH·밑줄 입력창·추천 검색어 순서를 따릅니다.
- 추천 검색어를 클릭하거나 검색어를 입력하면 현재 화면의 상품을 검색합니다.
